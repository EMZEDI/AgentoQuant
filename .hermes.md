# AgentoQuant — agent operating rules

Agentic hourly crypto trading system: Kraken spot, paper-first, human veto via Telegram, one editable pipeline. **This box is the runtime** (Hetzner `ubuntu-8gb-nbg1-1`). Nothing is implemented yet — the spec is complete and verified, the code starts at Task 1.

## Read first, in this order

1. `plan.md` — architecture, the hourly loop, standing priors, risks, and the appendix of verified facts and corrections. Trust the appendix over the prose where they disagree.
2. `tasks/todo.md` — 28 tasks in 5 phases, each with acceptance criteria and verification steps.
3. `tasks/schema_scaffold_addendum.md` — literal file tree, pinned dependency versions, canonical enums, ledger/brief/Decision Card record shapes.
4. `docs/HANDOFF.md` — how work is assigned, verified, merged and reported.

## Working rules

- **One task per agent prompt.** Never implement two tasks at once, and never build ahead of the assigned task.
- The addendum's file tree, enums and record shapes are **literal**. Import enums and record types from the named modules; never redeclare them locally. If a shape genuinely cannot be followed, say so and propose the smallest deviation rather than inventing your own.
- **Package name is `agentoquant`** (decided 2026-09-18). Read the addendum's `ctagent` as `agentoquant` everywhere and keep it consistent.
- Python **3.11** via `uv venv --python 3.11`. Pin every dependency from the addendum's table and commit the lockfile in Task 1; later tasks install from the lockfile. Never install into the uv-managed interpreter (it is externally managed and will refuse).
- **Done means the task's acceptance criteria and verification steps are satisfied with real command output** — not that code was written. Run the tests; paste what they printed.
- Report format is in `docs/HANDOFF.md`. No report, no merge.

## Hard safety rules

- **Paper/dry-run only until Task 26.** Never place, modify or cancel a real order. Private Kraken calls are read-only (`Balance`, `TradeBalance`, `TradeVolume`, `OpenOrders`, `ClosedOrders`, `Ledgers`, `Deposit*`). Never call `AddOrder`, `CancelOrder`, `AmendOrder`, `Withdraw*`, or any transfer endpoint.
- **Never move funds**, never request a withdrawal, never handle a withdrawal address. Funding is manual, triggered by a Telegram card that Shahrad answers himself — that is a plan rule, not a convenience.
- **Never print, echo, log or commit a secret.** Credentials live in `~/.config/agentoquant/credentials.env` (mode 600, outside the repo). `.env` stays out of git.
- **No Opus, no "big" profile, anywhere.** A config naming a disallowed model must fail validation at startup.
- **The Risk Gate is deterministic code** and can only shrink or reject a proposal — never enlarge it. No agent may bypass it.
- **Priors are Shahrad's.** Report when one hurts calibration; never edit one.
- **Random shuffled k-fold is banned.** Purged/embargoed CV, combinatorial purged CV and walk-forward are the only accepted numbers, with a deflated Sharpe and PBO gate before paper.

## Verified infrastructure — do not re-discover these

- Python 3.11.16 via uv 0.12.13; `freqtrade>=2026.5,<2027` resolves cleanly on 3.11 (ta-lib wheel, no source build).
- `kraken-cli` 0.4.1 at `~/.local/bin/kraken`; its MCP server is registered in Hermes as `kraken`, scoped to `market,paper` (no order placement). Add `account` for balances and `trade` only at Task 26.
- Kraken private API verified working. Quirks: the ledger endpoint is `/0/private/Ledgers` (not `Ledger`); `TradeVolume` returns fee data under `fees_maker`, keyed by `XXBTZUSD`; `OpenOrders`/`ClosedOrders` results nest rows under an `open`/`closed` key.
- Live fee tier is **Tier 1** (maker 0.4000%, next tier 0.3000% at $2,500 of 30-day volume; account volume ~$1,022). The Judge and Risk Gate price at the live tier read from `TradeVolume`; Tier 2 in backtests is the optimistic case.
- Telegram reuses the existing Hermes bot and gateway. Source `TELEGRAM_BOT_TOKEN` / `TELEGRAM_HOME_CHANNEL` from `~/.hermes/.env`; do not duplicate them.
- Grok X Search works through OpenRouter with the project's own key: `x-ai/grok-4.3` + `plugins:[{"id":"web"}]` + `x_search_filter{allowed_x_handles,...}`, cited posts, ~$0.0096/call. No xAI key needed.
- Kraken OHLCVT history: `https://assets.kraken.com/marketing/institutions/Kraken_OHLCVT_2026Q2.zip` (538 MB quarterly incremental) or the five ~2 GB `Kraken_OHLCVT_Full_2026Q2.zip.part0N` parts; checksums in `OHLCVT_Full_PARTS_SHA256SUMS.txt`. Rows are `timestamp,open,high,low,close,volume,trades`, no header, gaps omitted rather than zero-filled.
- CryptoRank: base `https://api.cryptorank.io/v2/` with an `X-Api-Key` header; `limit` must be 100/500/1000. **Unlocks and vesting are not in the free plan** (Pro only), so unlock data is best-effort and its absence fails closed for sleeve C.
- GDELT returns 429 from this IP ("one request every 5 s") with 10–13 s latency: confirmation layer only, with backoff, never a trigger.
- Keys required, not optional: Twelve Data, Alpha Vantage, CryptoRank. Keyless and verified: Bybit + OKX announcement APIs, Kraken public REST/AssetPairs, gold-api.com, DefiLlama fees/TVL, CoinGecko public, Google News RSS.

## Branch and worktree convention

- `main` is the integration branch and stays green.
- One branch per task: `task/NN-short-slug` (e.g. `task/01-package-skeleton`), created off `main`.
- Parallel tasks get one worktree each:
  ```
  git worktree add ~/work/agentoquant-wt/task-03 -b task/03-data-connectors main
  ```
- Serial tasks may work in the main clone on their branch; never two agents in one working tree.
- A task merges to `main` only after its acceptance criteria are verified and tests pass, and only after the phase agent has reviewed the diff.
- Never rewrite pushed history, never force-push `main`.

## Do not

- Do not edit `plan.md`'s prose. Corrections go into the appendix with a date.
- Do not add dependencies outside the addendum's pinned list without flagging it in your report.
- Do not commit credentials, DuckDB files, downloaded archives, or virtualenvs.
- Do not run anything against live keys. Paper only.
